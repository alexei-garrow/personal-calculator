# Personal Calculator: A Learning Journey

This project began as an exploration into building a calculator, evolving into a hands-on learning experience focused on understanding core JavaScript concepts, Git workflows, and different approaches to problem-solving.

## Project Goals

*   **Explore Calculator Implementations**: Dive into various methods for evaluating mathematical expressions, from simple manual parsers to external libraries.
*   **Understand Methodologies**: Document the advantages, disadvantages, and security implications of different evaluation strategies (e.g., `eval()`, `Function` constructor, manual parsing).
*   **Practical Git Workflow**: Learn and apply advanced Git concepts like branching, merging, conflict resolution, and `.gitignore` management.
*   **Iterative Development**: Experience the process of adding features, refactoring code, and managing project documentation.

## Current State

The calculator currently features basic arithmetic operations, but its evaluation logic is built on a sequential manual parser (as detailed in `manual-parser.md`). Future work will explore more robust parsing methods and additional features.

## Documentation

*   **`methods.md`**: A comprehensive guide to different expression evaluation techniques.
*   **`manual-parser.md`**: A line-by-line breakdown of the current manual parser implementation.
*   **`progress-journal.md`**: A detailed log of our learning journey, challenges faced, and solutions implemented.
